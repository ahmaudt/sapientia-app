Every foqos pattern, and what replaces it

Task 9 of the redesign plan restyled the retained screens without changing their layout, which is why they still read as foqos. This is the layout pass. It is written against the code as it stands: the file paths are real and the classes named exist in Sapientia/Theme/.
The five rules
01

Nothing is rounded

Corner radius is 0 everywhere but the radio dot. No RoundedRectangle survives outside the mark.
02

Cards are line drawings

No surface fill, no shadow, no material. A hairline border and four registration marks.
03

Rules replace containers

A list is an uppercase header with a rule under it and a rule under each row — not a grouped-list card.
04

One solid object

The accent fill belongs to the primary button, the selected segment, and data bars. Nothing else is filled.
05

Dark means rite

accent-900 is the ground for onboarding, the scan, the prayer and the timer set. Everything else is paper.

New to BlueprintComponents.swift
ComponentWhat it is
BlueprintListRowTitle, optional caption, trailing value or control, bottom hairline. The single row used on screens 07, 09, 20, 21, 22 and 24 — it replaces every Form row in the app.
BlueprintStatGridTwo or three cells, 1px gutters over a divider ground, numeral in Barlow Condensed at 24–30pt over an 11–12pt uppercase label. Already drawn inline in StatsGrid.swift; lift it out.
BlueprintHoldButtonFills left to right with accent as it is held, label flipping to accent-900 over the fill. Used by break, emergency unblock and erase.
BlueprintBarChartSquare bars, drawn baseline, accent full / accent-300 partial, uppercase axis labels.
ObservanceGridScreen 19’s calendar: rows named by the governing Sunday, seven square cells, filled when the day was kept.
BlueprintStageFull-screen presentation shell replacing .sheet detents: Cancel / title / action header, body, optional bottom action block. Light or accent-900.
Two things the mockups cannot do. Apple’s Screen Time picker (screen 08) and the NFC sheet render themselves and take no styling — frame them, do not fight them. And the shield extension still allows only title, subtitle, icon and two buttons in system fonts, so the block screen remains the one place where the type is not ours.
